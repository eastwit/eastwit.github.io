# 贾东睿（Dongrui Jia）· 个人主页

> 🌐 访问我的主页：**https://eastwit.github.io**

一个以「终端 / 命令行」为概念的开发者个人主页，深空风格，含粒子星空、打字机启动动画、技能进度条与经历时间轴。

## 技术栈

- 原生 HTML / CSS / JavaScript（单文件自包含，无框架依赖）
- Canvas 粒子动画
- IntersectionObserver 滚动揭示
- 全响应式适配（桌面 / 平板 / 手机）

## 页面模块

- 关于（About）
- 技能（Skills）
- 精选项目（Projects）
- 职业经历（Timeline）
- 联系（Contact）
